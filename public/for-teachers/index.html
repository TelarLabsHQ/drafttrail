Using DraftTrail with your class

Set up a writing task  Choose homework mode, or live in class with exit monitoring.

1. Give students the writing link

Use Set up a writing task to make the link, or share https://drafttrail.telarlabs.net/write/. To fill in the assignment name for them, add it to the link, for example:
https://drafttrail.telarlabs.net/write/?task=Essay%3A%20My%20Dream. Add &rules=1 to warn students each time they leave the page.

Term papers, case studies and citations

On the set-up page, choose a citation style (Chicago notes and bibliography, Chicago author-date, APA 7 or MLA 9), a word goal and sections. Students cite with one button and download their paper as a Word file with real footnotes. On the review page you see every writing session with its date, the sources, which ones were cited, and each pasted passage the student marked as a quote, so you can check it against the source. Students can move between computers by continuing from their .drafttrail file.

Writing in class with live monitoring

For short answers or essays written during the lesson, choose Live in class on the set-up page. It opens QuizPolice, where students join with a code and write in DraftTrail. You see live who leaves the page, big pastes and word counts, can lock students after too many exits, set a timer, and download all essays as one file to open on the review page. When the time runs out, essays are handed in automatically.

2. Ask for two things

The writing itself (copied into a doc or the assignment box) and the .drafttrail file from Download DraftTrail file. In Google Classroom, students attach the file with Add or create → File.

3. Review

Download the students' .drafttrail files from Classroom (you can select several), then open the review page and drag them in. Click a name to see the report and replay.

Tips

  • Tell students why: DraftTrail protects honest work and helps you understand their writing process.
  • Allow pasting of their own notes, and talk about it, rather than banning it.
  • Try "Try with three samples" on the review page to see what flags look like.
